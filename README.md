 میز بازی یک اپلیکیشن موبایل و سرویس تحت وب است که فضای یک کافه‌بازی آنلاین را شبیه‌سازی می‌کند. کاربران می‌توانند به اتاق‌های بازی مختلف بپیوندند، با افراد جدید آشنا شوند

مخزن فروشگاه تخصیصی میز بازی

وضعیت : درحال توسعه


<HR><br>


اکثر بازی‌ها و سرویس‌های اصلی توسعه یافته و قابل تست هستند:

بازی‌ها: مافیا، فوتبال، بیلیارد، رنگ و راز، افسون واژه، نبرد خنده

سرویس‌ها: اتاق انتظار، ارسال پیام و مدیریت دوستان، ضبط و تحلیل صوت، ایجاد و مدیریت گروه، مدیریت دارایی کاربران (درحال توسعه)

بازی‌های تکمیل شده تست آنلاین دارند و سرویس‌های درحال توسعه نیاز به تست و بهینه‌سازی دارند.

بازار بازی ایران ≈ حدود 70,000 میلیارد تومان. 
بازار بازی موبایل ایران ≈ حدود 5000 میلیارد تومان
